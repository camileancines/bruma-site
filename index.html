Política de Privacidade

Sua privacidade é
a nossa prioridade

Última atualização: junho de 2026

🔒 Resumo direto: o Bruma não coleta, não armazena e não transmite nenhum dado seu para servidores externos. Tudo fica no seu dispositivo.

1. Quem somos

O Bruma é um aplicativo iOS. Esta Política de Privacidade descreve como o app trata os dados dos usuários.

2. Dados coletados

O Bruma não coleta nenhum dado pessoal identificável. Não há cadastro, login, nome, e-mail ou qualquer informação que permita identificar o usuário.

Os dados inseridos no app, como registros de crises, intensidade, gatilhos e medicamentos, são armazenados exclusivamente no banco de dados local do dispositivo (via SwiftData / iCloud privado do próprio usuário, se habilitado).

3. Dados de saúde

O Bruma armazena informações de saúde inseridas manualmente pelo usuário (dores de cabeça, medicamentos, gatilhos). Esses dados:

  • Ficam armazenados localmente no iPhone ou no iCloud privado do usuário
  • Não são compartilhados com terceiros
  • Não são acessados pela desenvolvedora do app
  • São excluídos permanentemente ao desinstalar o app

4. iCloud

Se o usuário tiver o iCloud ativo, os dados podem ser sincronizados entre dispositivos do mesmo ID Apple via iCloud privado (CloudKit private database). Esses dados são criptografados pela Apple e acessíveis exclusivamente pelo titular da conta iCloud. A desenvolvedora não tem acesso a esses dados.

5. Dados climáticos

Para registrar condições climáticas no momento de uma crise, o Bruma consulta a API pública Open-Meteo (open-meteo.com) com a localização aproximada do dispositivo. Essa requisição:

  • É feita somente quando o usuário registra uma crise
  • Envia apenas coordenadas geográficas para obter dados meteorológicos
  • Não transmite nenhum dado pessoal ou de identificação

6. Localização

O Bruma pode solicitar acesso à localização do dispositivo exclusivamente para buscar informações climáticas locais no momento de uma crise. A localização não é armazenada e não é compartilhada.

7. Compras in-app

As transações de compra do Bruma Premium são processadas exclusivamente pela Apple via StoreKit. O app não coleta dados de pagamento, número de cartão ou informações financeiras de nenhum tipo.

8. Análise e rastreamento

O Bruma não utiliza nenhuma ferramenta de análise, rastreamento ou publicidade de terceiros (como Firebase, Amplitude, Mixpanel, Facebook SDK, Google Analytics, etc.).

9. Crianças

O Bruma não é direcionado a crianças menores de 13 anos. Não coletamos intencionalmente dados de crianças. Se você acredita que informações de uma criança foram inseridas no app, entre em contato para que possamos orientar a exclusão dos dados localmente.

10. Alterações nesta política

Eventuais alterações nesta política serão publicadas nesta página. O uso continuado do app após a publicação de alterações constitui aceite das novas condições.

Perguntas frequentes

O Bruma é gratuito?
Sim. O Bruma é gratuito para baixar e usar. O Bruma Premium, que desbloqueia gráficos avançados, relatório PDF e exportação CSV, é uma compra única dentro do app, sem assinatura mensal.
Meus dados ficam seguros se eu trocar de iPhone?
Se o iCloud estiver ativado no seu dispositivo, os dados são sincronizados automaticamente. Ao fazer login no novo iPhone com o mesmo ID Apple e instalar o Bruma, tudo estará lá. Caso contrário, os dados não são transferidos automaticamente.
Posso usar o Bruma sem internet?
Sim. O Bruma funciona completamente offline. A única função que requer internet é a captura de dados climáticos ao registrar uma crise, e ela é opcional.
Como exporto meus dados para o médico?
Com o Bruma Premium, vá em Estatísticas → Relatório PDF. Escolha o período (30, 90 ou 180 dias) e toque em "Gerar relatório". O PDF pode ser compartilhado via WhatsApp, e-mail ou impresso.
O Bruma está disponível para Android?
Por enquanto, o Bruma é exclusivo para iPhone (iOS 17+). Estamos avaliando uma versão para Android no futuro.
Posso cancelar a compra do Premium?
O Premium é uma compra única — não existe assinatura para cancelar. Se precisar de um reembolso, entre em contato com o suporte da Apple em reportaproblem.apple.com.
